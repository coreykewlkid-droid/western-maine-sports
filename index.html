Weekly Update Center

Manual · source-verified workflow

A repeatable weekly workflow to keep standings, schedules, and playoff status current through November. The log here is an in-session scratchpad (clears on reload) — for a durable record, edit js/data.js and redeploy, or export the log as JSON below.

Weekly Workflow

  1. Check MPA standings. Open the MPA sport pages (football seeding, soccer, field hockey and volleyball; check XC meet qualification separately) and copy the latest standings.
  2. Update results. Fill in wins/losses from the past week's games using downtownme.com, MaxPreps, and school athletics pages.
  3. Re-tag playoff status. Record a dated official rank within its sport, class and region. Label current playoff position separately from a clinched berth.
  4. Note key matchups. Add the next week's biggest games for the nine coverage schools.
  5. Log the update. Add a dated entry to the update log below, then redeploy.
Sources to check each week: mpa.cc · downtownme.com · MaxPreps · school athletics pages.
