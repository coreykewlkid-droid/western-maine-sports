# Western Maine 2026 Fall Sports Dashboard

Portable copy of the Western Maine Sports dashboard.

## Run the dashboard

The dashboard is a static HTML/CSS/JavaScript site. Open `index.html` in a browser, or serve this folder with a simple local web server.

## Data

The current dashboard data is already included in `js/data.js`.

## Data-generation scripts

`generate_data.py` and `build_xc.py` are included for future data updates. Perplexity-specific `/home/user/workspace/` paths were replaced with project-relative paths.

## Important

The dashboard does not require Perplexity to run.
